### BUG REPORT

*   **Título:** `[EquipmentForm] Equipamento com número de série com caracter especial`.
*   **Severidade/Prioridade:** Minor
*   **Passos para Reprodução:**
    1.  Navegar até a URL `/equipments`.
    2.  Cadastrar um equipamento com número de série com caracter especial.
*   **Comportamento Atual:** `O sistema não interrompeu a ação`.
*   **Comportamento Esperado:** `Deveria exibir a mensagem "Não é permitido caracteres especiais no número de série"`.
*   **Evidências:** Print da tela (mostrando o erro) ou vídeo rápido.
*   **Ambiente:** `Navegador Chrome v120 / Sistema macOS/ Ambiente de Homologação`.

**CT01-BRUTEFORCE:**
*   **ID/Título:** Um nome curto e descritivo. Ex: `CT-01 - Cadastro de equipamentos e alterações`.
*   **Pré-condições:** O que o sistema precisa ter antes de começar. Ex: `Usuário logado com permissão de administrador`.
*   **Passos:** Ações sequenciais.
    1.  Acessar a página de listagem de equipamentos.
    2.  Cadastrar um equipamento novo.
    3.  Editar o equipamento criado.
    4.  Verificar se as alterações persistiram.
  *   **Resultado Esperado:** O que deve acontecer se tudo estiver certo. Ex: `Toast de sucesso`.
